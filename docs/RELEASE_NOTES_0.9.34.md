# 0.9.34 リリース説明

## 状態と対象

本書は0.9.34向けの変更内容と更新時の注意をまとめたものです。
この環境では候補を作業領域内で作成・検証し、検証対象のソースへタグを付与する
ところまでを扱います。リリースパッケージの作成・公開は別マシンで行います。既存の展開済みバイナリ、
スキル設定、稼働サーバの更新・停止・再起動は行いません。

対象はMCPの複数編集・テキストアセット入力、authority展開マクロ、検索結果の
パスフィルタ、コードコピー、ページ一覧の長パス表示改善です。

## MCP利用者の更新

- `edit_page.operation`は、1件の編集でも配列で指定します。旧object形式は拒否します。
  selectorは処理開始時のセクションを追跡し、全操作の成功後に一度保存します。
  同じ呼出しで新設した見出しや、変更後の見出し名への参照を前提にせず、
  必要に応じてページ/TOCを再取得してください。
- `upload_page_asset`は`text`と`data_base64`をちょうど一方指定します。
  具体的な`text/*` MIMEとUTF-8であれば`text`を使用できます。空textは許可し、
  null・両方指定・空Base64は拒否します。テキストは前後空白・改行・BOM等を保持し、
  UTF-8の実バイト数でraw 10MiBを上限とします。取得側は従来のBase64です。
- `/mcp`のHTTP本文上限は64MiBです。raw容量上限とは異なり、JSON escapeと
  envelopeを含む受信容量が増えるためメモリ使用量にも影響します。
- 競合や`internal_error`の後は最新状態を再取得してください。
  保存後のエラーやファイル回収失敗から「未保存・副作用なし」とは推測できません。

サーバとスキルを同じ公開契約へ揃えて更新してください。配布用スキルと登録名・
endpointの調整は[SKILL_SETUP.md](../SKILL_SETUP.md)を参照してください。
既存の設定・認証情報・利用者のスキル編集を無条件に上書きしないでください。
サーバ再起動後はMCPセッションを初期化し直し、実際の`tools/list`を確認します。
接続表示が残っていても、旧セッションでは`Session not found`となる場合があります。

## authority展開

`{{mcp:authority}}`は、ブラウザ表示/編集プレビュー、ページ由来resource、promptの
元本文でrun設定のauthorityへ展開します。code内も対象です。保存sourceとraw取得は
維持し、生成結果やpromptの挿入引数値は再展開しません。
直前の奇数個のバックスラッシュで展開を抑止できます。

設定変更の反映にはサーバ再起動とHTML再取得/MCP再接続が必要です。
Hostヘッダやブラウザoriginからauthorityを推測する変更はありません。

## ブラウザUI

- 検索結果の「パスに含む文字列」で、取得済み最大100件を前後空白除去後の
  リテラル部分一致で絞ります。大小文字を区別し、正規表現/globではありません。
  フィルタだけでは再検索せず、表示件数と取得件数を分けて表示します。
- 閲覧・過去本文・編集プレビューのコードフェンス内側右上に、枠なしのコピーアイコンを
  配置しました。表示段階のコードをコピーし、Mermaidは元コードをコピーします。
  authority展開やparserの改行処理後の文字列であり、保存sourceやassetの元bytesとは
  異なる場合があります。ReadOnlyでも利用でき、失敗はボタン付近へ表示します。
- 長いページパスでも一覧を操作できるよう幅制約を修正しました。狭幅では更新情報を
  別行へ配置し、パンくずの省略表示・キーボード操作・復元導線を維持します。

コピーの可否はブラウザの権限・接続条件にも依存します。Clipboard APIが明示的に
拒否した後はfallbackしません。API未提供時だけユーザ操作内で同期fallbackを試みます。
Octicons copyのMIT通知は実行ファイルに含まれ、`/static/licenses/octicons.txt`で参照できます。

## 案内・ログ・保留事項

- MCPのページ作成・更新・部分編集・追記・リネームが全文索引へ反映されない問題を
  修正しました。保存成功後に影響ページを同期し、amendと再帰renameも反映します。
  索引更新が失敗した場合は保存済みの正本を維持し、固定のinternal_errorを返します。
  過去の未索引データを含む既存環境の索引を自動再構築する変更は行いません。
- Sandboxの更新は初期雛形に対する変更です。既存Sandboxは自動更新されません。
  利用者の編集を保持し、必要な説明・例だけを確認して反映してください。
- 本文秘匿のため、製品loggerは`rmcp`/`rmcp_actix_web`依存診断ログを全レベルで
  除外します。診断情報が減る点に留意し、独立logger/subscriberを追加する場合も
  同等のtarget除外が必要です。
- ページ変更のカスタム通知によるエージェント自動開始、閲覧中ページの変更検出と
  自動/半自動更新、これらに対応するスキル改訂は未達の保留項目です。
  対象クライアントの対応・契約・設定を根拠付きで確認し、ユーザの再開判断を受ける
  まで実装・再調査を再開しません。

詳細な公開契約は[MCPツール仕様](MCP_TOOL_SPECS.md)、
[マクロ仕様](MACRO_SPECS.md)、[UI仕様](FRONTEND_UI_SPECS.md)を参照してください。
